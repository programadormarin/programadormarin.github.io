# Portfolio Project Context

## The Core Value
A high-performance, visually stunning portfolio for Hermenegildo Marin Júnior, demonstrating modern frontend aesthetics and strong backend architecture expertise.

## What This Is
A personal portfolio website built with Vanilla HTML, CSS, and JS (bundled with Vite). It acts as a digital resume and a showcase of skills, professional experience, and certifications.

## Target Audience
- Recruiters
- Engineering Managers
- Fellow Developers

## Key Features
- **Hero Section**: High-impact introduction.
- **About / Summary**: Brief professional overview.
- **Skills**: Visual representation of tech stack (Go, PHP, Node.js, AWS, Kubernetes, etc.).
- **Experience Timeline**: Journey from 2009 to Present.
- **Contact / Links**: Easy access to GitHub, LinkedIn, Email.

## Requirements

### Active
- [ ] Must be extremely fast and lightweight.
- [ ] Must use rich aesthetics (dark mode, glassmorphism, dynamic typography).
- [ ] Must be fully responsive.
- [ ] Code must be clean and semantic.
- [ ] SEO optimized.

### Out of Scope
- Backend functionality or CMS (static is sufficient).
- Complex framework usage (React/Vue).
